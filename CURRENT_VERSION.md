## Ежедневный выбор

Настройки находятся в `commando-settings.json`. Дата определяется по Europe/Moscow. Цикл: каньон → завод → храм → побережье. Новый день выбирает следующую сцену; повторный запуск в тот же день сохраняет выбор. Последний опубликованный выбор хранится в `output/commando-state.json`. Дополнительная проверка запрещает повтор последней опубликованной сцены, включая восстановление после пропущенных запусков.

При первом запуске новая версия читает локацию из прежнего SVG и выбирает другую. SVG и состояние публикуются одним Git-коммитом; при изменении output во время генерации публикация прерывается без перезаписи. Ошибка GitHub API сохраняет прежнюю опубликованную картинку и не подменяет её демо-данными.

GitHub Actions настроен на 00:17 и 12:17 Москвы (21:17 и 09:17 UTC). Расписание запускается GitHub и может выполняться с задержкой. Обновление календаря в течение дня не переключает локацию.

## Подписи и клетки

Ник со слэшем — 21 px полужирным. Названия месяцев — английские сокращения, 15 px полужирным. Последний неполный месяц подписывается, включая NOV у правого края; подписи не обрезаются и не накладываются друг на друга. Клетки — 18 × 18 px, шаг 20 px, зазор 2 px, скругление 3 px. Центры клеток и геометрия попаданий сохранены. У побережья сохранён общий профильный масштаб.

Генератор получает текущий календарь через GitHub API. Токены хранятся в GitHub Secrets; в SVG и состояние они не записываются.
