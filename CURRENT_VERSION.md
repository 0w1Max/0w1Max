Оформление табличек:

- Каньон — угловатая рамка из песчаника, трещины, терракотовая поверхность, песочная надпись.
- Завод — металлическая панель со скошенными углами, крепежом и небольшими сигнальными полосами.
- Храм — каменная плита с резными углами, мхом и бирюзовым водным орнаментом.
- Побережье — тёмно-синяя морская панель со светлыми углами и пиксельными волнами.

Главная надпись GAME OVER собрана из SVG-пикселей и не зависит от шрифтов. Появление остаётся после завершения зачистки клеток. Затем табличка исчезает по прежней шкале прозрачности; возврат бойца и восстановление календаря сохранены.

Закреплённые исходные SVG v2.4.0 оставлены без изменений. Новые превью получены заменой только внутреннего оформления группы завершения; календарь, фон, маршрут, выстрелы, размер полотна и внешняя анимация прозрачности сохранены побайтно. Это прежние снимки календаря, не новый запрос API.

Проверено локально: 66/66 тестов, XML, уникальность идентификаторов, ссылки на спрайты и визуальная читаемость всех четырёх табличек в контексте сцен. Эти результаты не означают, что GitHub CI уже прошёл.

[Точные коммиты и Git blob SHA](commando-release.json). Новые превью находятся в рабочей ветке; main/output, публичный профиль и расписание публикации не обновлялись.
