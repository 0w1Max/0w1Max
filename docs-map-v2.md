# Commando Activity — процедурные препятствия и платформы (v2.2)

## Правила карты

- Препятствия: **0–3**, платформы: **0–2**. Пустой уровень допустим.
- Выбор по воспроизводимому `seed`: та же активность GitHub и тот же seed дают ту же карту.
- Препятствия подбираются без повторения видов; если платформы две, они одинакового вида и ширины, но разные карты по `seed` могут использовать другие платформы.
- Доступные препятствия: `jungle-rock`, `fallen-log`, `sandbags`, `stone-ruin`, `tree-stump`, `supply-crate`.
- Доступные платформы: `wooden-bridge`, `mossy-stone`, `vine-ledge`, `metal-catwalk`, `camo-platform`.
- Отдельные слои: `scripts/mission.mjs` — количество, виды, размещение, валидация; `scripts/level-art.mjs` — оригинальные векторные 8-bit тайлы.
- Если безопасного свободного места не хватает, генератор **уменьшает** количество препятствий. Не ставит запасной ящик под платформой.
- Левый коридор зарезервирован для возврата бойца после `MISSION COMPLETE`.
- Платформы имеют высоту, доступную для прыжка с земли; прыжки, стрельба и сложность целей остаются неизменными.
- Никаких внешних ассетов и JS внутри итогового SVG.

## Контроль качества

Локально: `node --test tests.mjs`, `node scripts/generate.mjs --demo --output generated/demo.svg`. В GitHub Actions проверяются тот же тестовый календарь и настоящий календарь `0w1Max`.

Автотесты проверяют 1000 вариантов `seed` на допустимое число объектов, отсутствие повторов препятствий и различий между платформами на одной карте, перекрытий и доступность пустых карт. Отдельно проверяются маршруты полных миссий и отсутствие проходов сквозь препятствия.

Открыть Draft PR #1: в его начале встроено анимированное SVG-поле с реальным календарём GitHub. Основной README и ветка `main` остаются без изменений. Обновление текущего предварительного SVG происходит только после успешного GitHub Actions.
