# Code and asset rights

The MIT grant in [LICENSE-CODE](LICENSE-CODE) covers original project code under `scripts/`, tests, workflow configuration and documentation. It does **not** grant rights to all artwork in this repository or to third-party trademarks.

| Resource | Status |
|---|---|
| Original generator / mission / publication code | MIT, see LICENSE-CODE |
| Fonts and derived glyph outlines in assets/fonts | Their accompanying SIL Open Font License files apply; preserve notices |
| Soldier sprites, backgrounds, terrain atlases and derived SVG previews | Complete provenance and redistribution permissions have not been established in the repository; excluded from the code license |
| Technology logos, profile icons, project names | Third-party rights may apply; excluded from the code license |

This is an independent project, not an official Contra or Konami product. Referencing a game style does not establish permission to redistribute its original artwork. A public GitHub repository and the ability to fork are not a blanket artwork license.

The installation guide describes a technical reuse path. For a broadly redistributed or commercial artwork bundle, first establish the source/license of every graphic or substitute artwork you own or have permission to use. No claim of completed rights clearance is made by release 2.7.0.
