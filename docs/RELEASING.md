# Релиз и восстановление

1. Зафиксируйте утверждённый внешний вид отдельным коммитом. Для 2.7.0 это `bf8f10350b0c82fa2e651b318b8b83298d821a36`.
2. Обновите version в `commando-settings.json` и `commando-release.json`, CURRENT_VERSION и CHANGELOG. Не меняйте seeds сегодняшней сцены без миграции.
3. Запустите все `tests*.mjs`, сгенерируйте демо, проверьте XML и живые кадры четырёх официальных локаций. Проверьте отсутствие секретов и демо-данных в production.
4. Сохраните текущие SHA default branch и output. Интегрируйте код, сохранив параллельные изменения профиля. Создайте неизменяемый version tag на итоговый коммит.
5. Push кода в default branch запускает публикацию. Если менялась только документация, используйте Actions → Run workflow.
6. Дождитесь success, проверьте версию в `output/commando-activity.svg`, JSON состояния, совпадение SHA-256 и дату календаря. Откройте прямой SVG и профиль. Запущенный workflow ещё не означает успешный релиз.

## Сохранность публикации

SVG и JSON состояния записываются в одном коммите. Во время подготовки сверяется исходный output SHA; при изменении публикация прекращается. Обновление ref выполняется без force. При самом первом запуске создаётся новая ветка output; если её одновременно создал другой процесс, операция завершится ошибкой вместо перезаписи.

В workflow используется отдельная concurrency group. Автоматический rollback не реализован. При ошибке генерации прежний output сохраняется. Резервной копией служат сохранённый SHA и история Git.

## Восстановление

При ошибке API/PAT исправьте причину и повторите workflow. Не публикуйте fixtures вместо настоящего календаря.

При повреждении состояния сначала остановите публикации и сохраните текущий output SHA. Найдите предыдущий коммит, где SVG и JSON образуют согласованную пару. Восстановите оба файла **вместе новым коммитом**, без переписывания истории. Проверьте checksum и дату; затем запустите workflow. При попытке установить состояние с будущей датой генератор остановится.

Откат кода и output — разные операции: возврат старого исходника сам по себе не восстанавливает картинку. Для отката релиза используйте обычный revert кода и контролируемую повторную генерацию. Не смешивайте SVG одного коммита с состоянием другого.
