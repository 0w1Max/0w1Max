# Commando Activity

Автономная SVG-анимация графика вкладов GitHub в стиле восьмибитного run-and-gun. Персонаж патрулирует уровень, прыгает через препятствия и стреляет по клеткам календаря. Это анимация, а не игра с управлением с клавиатуры. JavaScript выполняется при генерации; профиль показывает SVG со встроенной анимацией SMIL.

Официальные миры: каньон, завод, храм и побережье. Каждый имеет свою палитру, фон, платформы, препятствия и финальную панель. Геометрия календаря и типографика общие. Поддерживаются календари до 55 колонок. Прочность клеток зависит от уровня активности. Маршрут, прыжки, стрельба и восстановление календаря рассчитываются генератором.

Для запуска и тестов достаточно Node.js 22: npm-пакеты не требуются. Сервер, база данных и GitHub Pages не нужны. Actions публикует SVG в `output`, профиль встраивает его как картинку.

Поток данных: GitHub GraphQL → проверка владельца токена → нормализация календаря → выбор локации → уровень и миссия → SVG → валидация → коммит SVG и состояния в `output` → README.

Ошибка API не заменяет данные демонстрационными. Токен не записывается в SVG или состояние. Демо используется только для проверок. Установка рассчитана на личные аккаунты; организационные профили текущим workflow не поддерживаются: владелец PAT должен совпадать с владельцем профиля.
