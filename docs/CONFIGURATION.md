# Настройки

Основной файл — `commando-settings.json`. Изменяйте через отдельную ветку с проверками.

| Поле | Назначение |
|---|---|
| version | Версия кода и опубликованного состояния |
| timezone | Поддерживаемое значение: Europe/Moscow |
| rotation.mode | Поддерживаемое значение: daily-cycle |
| rotation.epoch | Опорная дата цикла YYYY-MM-DD |
| rotation.order | Ровно четыре уникальные локации: desert, industrial, temple, coast |
| rotation.preventConsecutiveRepeats | Должно быть true |
| seeds | Неотрицательный целый seed карты для каждой локации |

Seeds закрепляют воспроизводимость; ротация меняет локацию по дате, а не случайно при каждой загрузке профиля. При изменении seed уже опубликованной сегодня локации генератор остановится: меняйте такой seed при переходе на следующий день или выполняйте отдельную проверенную миграцию состояния.

## Общий внешний вид

Официальный эталон — завод. Кадр 1200 × 469, viewBox `0 -32 1200 469`; все четыре локации используют один масштаб. Ник monospace bold 21 px, месяцы monospace bold 15 px. Координаты базовых линий -8 и 46. Клетки 18 × 18, шаг 20, скругление 3; начало поля (72, 60). Из-за верхней области viewBox первая строка видна на 92 px от края изображения.

`scripts/profile-hud.mjs` задаёт типографику и месяцы; `scripts/mission.mjs` — WORLD и геометрию; `scripts/generate.mjs` — общий viewport и палитры. Менять геометрию нужно совместно с проверкой попаданий, прыжков и всех локаций. Цвета текста, клеток и обводок зависят от локации. Фон не должен задавать отдельный масштаб календаря.

## Расписание и ручной запуск

Workflow `.github/workflows/commando-activity.yml`: cron `17 21,9 * * *` в UTC, то есть 00:17 и 12:17 Москвы. Это желаемое время, GitHub может задерживать запуск. Ручной запуск выполняется через Actions → Run workflow. Код публикуется только из default branch.

## CLI и окружение

| Вход | Где используется |
|---|---|
| GITHUB_USER | Логин для CLI; workflow устанавливает владельца репозитория |
| GH_TOKEN / GITHUB_TOKEN | PAT для CLI GraphQL; приоритет зависит от CLI, задавайте только одну переменную |
| COMMANDO_READ_USER_TOKEN | Имя repository secret, workflow передаёт его как GH_TOKEN |
| COMMANDO_LOCATION | Низкоуровневый generate.mjs: конкретная сцена; не меняет daily publication |
| COMMANDO_MAP_SEED | Низкоуровневый generate.mjs: seed; daily publication берёт seed из настроек |

`generate.mjs` поддерживает `--demo`, `--output`, `--seed`; `publish-daily.mjs` — `--demo`, `--previous-state`, `--output`, `--state-output`. Демо не требует токена и не должно публиковаться в профиль. Живой daily CLI требует путь к предыдущему состоянию; для первого запуска файл содержит JSON `null`. Штатный workflow создаёт его сам.
