## Ограничения и дальнейшие задачи

- Полная цепочка происхождения/лицензий всех старых графических ресурсов не установлена. Для полностью открытого распространяемого art-пакета нужна проверка или замена ресурсов.
- Сценарий нового пользователя проверяется через тестовый GitHub API; создание реального чужого аккаунта и использование чужого PAT не выполняются.
- Поддерживается личный аккаунт и документированный classic PAT с read:user. Организационные профили и fine-grained PAT требуют отдельной проверки.
- Генератор не содержит npm-зависимостей, но художественные компиляторы требуют Python-библиотек и не являются переносимым установщиком ресурсов.
- Исторические preview-файлы могут содержать старые размеры/шрифты и не обновляются вместе с production. Актуальные настройки определяют исходники и манифест релиза, а результат — output.
- Структура репозитория совмещает персональный профиль и генератор. Отдельный публичный репозиторий продукта можно выделить позже, сохранив текущую установку через fork.
