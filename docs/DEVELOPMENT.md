## Локальная проверка

Используйте Node.js 22. Из корня репозитория запускайте полный набор встроенным Node test runner: `node --test tests*.mjs`. Затем создайте демо командой `node scripts/publish-daily.mjs --demo`. Результат — `generated/commando-activity.svg` и JSON состояния. Откройте SVG непосредственно в браузере: статичный PNG не проверяет анимацию.

Для настоящего календаря задайте GITHUB_USER и PAT через защищённое окружение; не вставляйте токен в командную историю. Демо-режим явно маркируется и не используется как fallback при ошибке API. Runtime не требует npm install; Python нужен только для пересборки художественных атласов, fontTools — для исторических шрифтовых вариантов. Компиляторы ресурсов — инструменты автора, не обязательные шаги установки игры.

`scripts/preview-profile-font.mjs` воспроизводит четыре утверждённых кадра из сохранённого реального снимка календаря. Это удобная дизайнерская проверка; снимок не обновляется автоматически и содержит логин автора. Для собственного профиля используйте publish-daily, а не этот preview-скрипт.

## Что проверяется

Тесты покрывают нормализацию 53–55 недель, стабильность seed, коллизии и реальные ключевые кадры прыжка, направление ствола и начало пули, полную обработку прочности клеток, маршрут в обе стороны, timing финальной панели, ротацию на границах дат и одинаковый HUD всех четырёх локаций. Проверки output-store моделируют чужой личный репозиторий без output, legacy-миграцию, повреждённое состояние, ошибки API и конкурентное обновление.

При изменении движения проверяйте синхронность пули, персонажа и клетки в общей системе координат. Отдельное масштабирование календаря или всей одной сцены снова нарушит единый внешний вид. При изменении атласа размеры визуального объекта и коллизии должны совпадать. Экспериментальные миры jungle/snow/volcano не включаются в официальный daily-каталог без отдельного изменения валидации и тестов.

Новый вклад: отдельная ветка → небольшое изменение → подходящие тесты → живое превью всех затронутых локаций → PR. Личные профильные проекты и README автора не являются конфигурацией генератора.
