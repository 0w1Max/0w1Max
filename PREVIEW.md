# Commando Activity v2 — как посмотреть анимацию

Проект находится в Draft PR, профильный `README.md` не меняется.

1. Открой [проверку в GitHub Actions](https://github.com/0w1Max/0w1Max/actions/workflows/commando-activity-check.yml).
2. Выбери последний успешный запуск ветки `feature/commando-activity-svg-v1`.
3. Внизу скачай **Artifacts → commando-svg-preview**.
4. Распакуй ZIP и открой `real.svg` в Chrome. `demo.svg` использует тестовый календарь и помечен `DEMO / TEST DATA`.

Боец с синей повязкой проходит уровень в обе стороны, прыгает через препятствия, забирается на платформы и стреляет из дула по всем зелёным квадратам. Когда все активные клетки погасли, появляется `MISSION COMPLETE`, затем цикл повторяется.

Файл — самодостаточный анимированный SVG, не видео и не GIF. Прежде чем публиковать его в профиле, проверяем мобильное отображение, темп анимации и качество спрайтов.
