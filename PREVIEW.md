# 0w1Max Commando Activity — предварительная версия

Это технический прототип анимированного SVG для GitHub-профиля, **не опубликованный на главной странице**.

- Один боец с синей повязкой бежит внизу сцены и стреляет вверх.
- Квадраты строятся из 53 недель × 7 дней GitHub Contributions.
- Игровой фон: горы, джунгли, пиксельные пальмы и платформа.
- При попадании клетка временно гаснет, затем восстанавливается при повторении анимации.

## Посмотреть результат

1. Открой вкладку [Actions](https://github.com/0w1Max/0w1Max/actions/workflows/commando-activity-check.yml).
2. Выбери успешный запуск на ветке этого PR.
3. Скачай `commando-svg-preview` из раздела **Artifacts**.
4. Открой `real.svg` в браузере. В архиве также находится `demo.svg`, который **не содержит реальные данные аккаунта**.

Файлы в PR ещё не подключены к главному `README.md`. Публикация в ветку `output` выключена без отдельного разрешения.
