## Вулканическая зона V4

Три процедурные раскладки с одним сохранённым снимком активности GitHub.

| Seed | Платформа | Анимированная карта |
| --- | --- | --- |

| 82 | Стальная ферма с Х-образными раскосами | [Открыть SVG](preview/volcano-rift-v4-82.svg?raw=1) |

Seed управляет раскладкой и декором. Настил собирается из повторяемых секций и
совпадает с игровой линией земли. Препятствия и платформы хранятся отдельными
спрайтами в `assets/volcano-sprites.json.gz.b64` и встраиваются в итоговый SVG.

Текущий Draft PR не меняет публичный профиль GitHub. Предпросмотр загружается через **Actions → успешный запуск → Artifacts → `commando-svg-preview`**.

В архиве два файла:

- `demo.svg` — анимация на тестовом календаре с маркировкой `DEMO / TEST DATA`;
- `real.svg` — анимация на календаре `0w1Max`, полученном из GitHub GraphQL в режиме только для чтения.

Боец снизу стреляет из дула по диагонали, непредсказуемо выбирает доступные цели, перемещается по сцене, перепрыгивает небольшие камни, использует возвышения, зачищает все зелёные клетки и показывает `MISSION COMPLETE`. Тёмные дни без активности остаются фоном. После финального попадания боец ещё движется, перепрыгивает препятствия и возвращается к старту; клетки восстанавливаются последовательной волной. Последний и первый кадры совпадают по позиции и позе — без телепорта.

**Примечание:** GIF не используется. Рендерится самостоятельный SVG с заранее рассчитанными анимациями. Перед публикацией требуется отдельная визуальная приёмка и разрешение на merge.

## v2.1 — этап 2: синхронизация ствола и эффектов

- Геометрия точки дула и вектор оси ствола определяются общей функцией `aimGeometry`; планировщик и SVG используют её без отдельной подгонки траектории.
- Верхняя часть позы `aim` поворачивается вокруг опорной точки, нижняя сохраняет положение; лицо персонажа зеркалится при повороте налево.
- Во время стрельбы **не используется** исходный спрайт `shoot-stand`, в котором уже нарисована вспышка. Вспышка отрисовывается один раз — непосредственно из дула, вместе с пулей в той же системе координат.
- Пуля целиком перемещается вдоль направления оружия и скрывается в момент попадания.
- Добавлены два повторно используемых пиксельных эффекта: повреждение без уничтожения и более выраженный взрыв при последнем попадании.
- `main` не изменён, работа только в Draft PR. Следующий этап: нормализация спрайтов и плавный финал.

### Планировщик целей (v2.1)

Стрельба больше не идёт по рядам: случайно выбираются доступные цели, причём вертикально перекрытые клетки защищены, а траектории пуль проверяются на пересечение. Результат воспроизводится по seed.

## v2.1 — плавное завершение миссии

- После последнего попадания показывается `MISSION COMPLETE`; боец завершает позу, добегает до стартовой точки с учётом препятствий и при необходимости делает короткий прыжок.
- Каждая разрушенная клетка плавно восстанавливается в направлении слева направо за 0,3 секунды, при этом уже восстановленные клетки остаются видимыми.
- Стартовое и конечное положения (координаты, направление, `idle`) совпадают, поэтому в повторяющейся SMIL-анимации отсутствует мгновенное смещение.
- Вся карта и полный календарь остаются неизменными; эффекты действуют только внутри SVG.
- Публикация отключена, `main` не меняется.
