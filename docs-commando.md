# 0w1Max Commando Activity — SVG-генератор v2 (Draft PR)

Собственная 8-битная сцена по принципу Pac-Man Contribution Graph. Код построения уровня и движения бойца оригинальный. На главной GitHub пока не опубликовано.

## Механика v2

- 53 недели × 7 дней из GitHub GraphQL: **все дни с ненулевой активностью** становятся целями, нулевые дни остаются тёмными.
- Один боец с синей повязкой патрулирует поле вправо → влево → вправо, останавливается, прицеливается и стреляет из точки дула под углом в заданную клетку.
- Каждому активному квадрату соответствует ровно одно попадание; он исчезает после попадания, затем возникает надпись `MISSION COMPLETE` и цикл повторяется.
- По воспроизводимому seed строятся 1–3 препятствия и 1–2 платформы. Боец прыгает через препятствия, иногда подпрыгивает, запрыгивает на платформы, стреляет с них и спрыгивает.
- Для отладки учтены ширина спрайта, безопасные интервалы между препятствиями, подходы и точки приземления.
- Генератор создаёт один самодостаточный SVG с SMIL-анимацией. Сторонних npm-пакетов, внешних изображений и телеметрии нет.

## Архитектура

- `scripts/mission.mjs` — чистый детерминированный планировщик маршрута, платформ, прыжков и целевых выстрелов.
- `scripts/generate.mjs` — GraphQL, валидация календаря, векторные спрайты и экспорт SVG.
- `assets/sprites.json.gz.b64` — исходные 16 кадров бойца с синей повязкой.
- `fixtures/demo-calendar.json.gz.b64` — демонстрационные данные, помеченные `DEMO / TEST DATA`.
- `tests.mjs` — 14 регрессионных проверок, в том числе 100 seed для контроля столкновений.

## Проверка

Локально достаточно Node.js 22+; npm не требуется.

```text
node --test tests.mjs
node scripts/generate.mjs --demo --output generated/demo.svg
```

Для настоящего календаря необходимы переменные окружения `GITHUB_USER` и `GITHUB_TOKEN` либо `GH_TOKEN`. Токен не выводится и не сохраняется. Ошибка API не заменяется фальшивым календарём.

В **Actions → Проверка 8-bit генератора → успешный запуск → Artifacts** скачай `commando-svg-preview`: он содержит `demo.svg` и `real.svg`. В этом workflow разрешение только `contents: read`, поэтому на главную страницу ничего не публикуется.

Отдельная автоматическая публикация выключена проверкой `vars.COMMANDO_ACTIVITY_PUBLISH == 'true'`; включать её и выполнять merge разрешается только после самостоятельной визуальной приёмки и отдельного решения владельца.

## Известные ограничения

- Полный цикл длится столько, сколько необходимо для поражения всех активных клеток: в тестовом календаре ~80 секунд, а не 10 секунд.
- SVG может быть крупным (~1 МБ без сжатия); перед merge нужны проверка нагрузки и мобильного отображения.
- Реальный генератор построен на публичном календаре пользователя и не запрашивает содержание приватных репозиториев.
