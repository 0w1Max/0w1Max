# 0w1Max Commando Activity — черновик генератора

Собственный SVG-генератор игрового графика contributions. Один боец с синей повязкой бежит внизу пиксельного уровня и стреляет вверх по клеткам календаря GitHub. Концепция повторяет **технический принцип** Pac-Man Contribution Graph, но не использует его код или внешние сервисы.

## Текущий статус

- 53 недели × 7 дней, уровень из реальных данных GitHub GraphQL.
- Исходный 16-кадровый спрайт-лист закодирован как векторные фигуры; данные спрайтов упакованы в `assets/sprites.json.gz.b64`, чтобы сохранить точные формы и цвета кадров.
- Анимация — SVG + SMIL, без встроенного JavaScript в GitHub README.
- Ветка PR содержит тестовый workflow с `contents: read`: проверяет тестовые данные, настоящие contributions и корректность XML, **не публикуя** результат.
- Второй workflow (`commando-activity.yml`) предназначен для ежедневной генерации **только после merge в основную ветку**; создаёт/обновляет ветку `output`. Его запуск и публикация пока не подтверждены.
- В README главного профиля анимация пока не добавлена. Существующая обложка остаётся без изменений.

## Запуск локально

Требуется Node.js 22+, установка npm-пакетов не нужна.

```text
node --test tests.mjs
node scripts/generate.mjs --demo --output generated/demo.svg
```

Для реальных данных (только с собственным токеном с минимальными правами):

```text
GITHUB_USER=0w1Max GITHUB_TOKEN=<ваш_токен> node scripts/generate.mjs --output generated/real.svg
```

Никогда не сохраняйте токены в файлах репозитория. Ошибки GitHub API не заменяются синтетическими данными. Отдельные приватные репозитории и их названия не запрашиваются.

## Предпросмотр в Draft PR

- GitHub Actions `Проверка 8-bit генератора` прикладывает к успешному запуску артефакт `commando-svg-preview` с `demo.svg` и `real.svg` (хранение до 7 дней).
- `demo.svg` основан на синтетических данных и не должен отображаться на публичной главной как настоящая статистика.
- `real.svg` собирается в CI через GitHub GraphQL и сохраняется только для просмотра в артефакте; публикации в `main` и `output` нет.
- Посмотреть архив можно в разделе **Actions → успешный запуск → Artifacts → commando-svg-preview**.
- Изменения внешнего вида сцены проверяются отдельно по кадрам в Chromium (0, 2.52, 5.15, 9.85 секунды).

## Защита публикации

Даже после слияния workflow публикации не стартует, пока владелец репозитория отдельно не установит переменную Actions `COMMANDO_ACTIVITY_PUBLISH=true`. До такого разрешения оставляем её отсутствующей или `false`. Запуск вручную при выключенной переменной также будет пропущен. Генератор не использует стороннюю телеметрию.

## Что проверяем до публикации

1. CI: четыре теста и получение реального календаря.
2. SVG отображается с работающей анимацией в браузере и README GitHub (тёмная и светлая темы).
3. Проверка размера, качества покадрового движения, мобильного просмотра.
4. Только после этого — отдельное решение о merge и включении на главной странице.
